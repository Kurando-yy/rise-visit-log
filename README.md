# RISE南関町 来店記録タブレット

理容室の来店記録を、お客様ご自身のタップで取るための画面です。

- 大きなボタン・1画面1問・戻るボタンなし・文字入力なし
- 画面遷移：ご来店は？ → 性別 → ご希望 → 詳しく → （条件つき）→ お会計
- 確定から3秒で最初の画面へ自動復帰

## 料金の変更

`menu.config.js` の `price` / `kariPrice` / `longAddPrice` の数値だけを書き換えてください。
画面のコードは触る必要がありません。有効期間は同ファイル冒頭の `effective` に記載しています。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `menu.config.js` | **メニューと料金の唯一のマスタ** |
| `menu.logic.js` | 画面遷移と金額計算（DOM非依存） |
| `ui.flags.js` | 挙動の切替（1択時に画面を飛ばすか／自動復帰の秒数） |
| `app.js` | 画面制御 |
| `submit.js` | 記録の送信（送信先は未設定のプレースホルダ） |
| `gas/Code.gs` | Google スプレッドシート側の受け口（未デプロイ） |
| `scripts/verify_reachability.js` | 全メニューに到達できるかの自動検査 |
| `scripts/layout_check.html` | ボタンのはみ出し・文字切れの目視/自動検査 |

## 注意

送信先URL・スプレッドシートIDは**プレースホルダのまま**です。実際の接続情報はこのリポジトリに含めません。
